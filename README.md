# 아이해담 AIHAEDAM

엄마의 기준으로 고른, 아이를 위한 좋은 수산물.

## 페이지
- `index.html` — **아이해담 사업성 검토** (수익 구조, 운영 리스크, 공급망, 안전·배상책임, 여름 배송, 리스크 반영 손익, 단계별 전략, 체크리스트)
- `site.html` — **아이해담 브랜딩 홈페이지 예시** (홈, `#eel` 제품 상세, `#story` 이야기, `#brand` 내부용 브랜드 가이드)

사업성 검토 페이지의 "홈페이지 예시 보기" 버튼으로 예시 사이트에 들어가고, 예시 사이트 상단 띠로 돌아옵니다.

## 운영 설정 (홈페이지 예시)
`site.html` 하단 `<script>`의 `SITE` 객체에서 수정합니다.
- `smartstoreUrl`: 스마트스토어 상품 주소를 넣으면 모든 구매 버튼이 연결됩니다.
- `categories`, `info`, `faq`: 카테고리, 제품 정보 표, 자주 묻는 질문.

## 주의
- 금액·판매량은 모두 검증 전 가정치이며, 법률·세무·보험 자문이 아닙니다.
- 두 페이지 모두 검색엔진 수집 금지(noindex) 표시가 있습니다. 다만 저장소가 공개 상태이면 GitHub에서 코드를 누구나 볼 수 있습니다.
- 이미지는 임시 그래픽이며, 확인되지 않은 제품 정보는 "확인 후 기재"로 비워 두었습니다.
