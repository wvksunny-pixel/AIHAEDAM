# 아이해담 AIHAEDAM

엄마의 기준으로 고른, 아이를 위한 좋은 수산물.

프리미엄 어린이 수산물 브랜드 **아이해담**의 브랜드 홈페이지 시안입니다. 파일 하나(`index.html`)로 동작하는 정적 사이트입니다.

## 페이지
- `index.html` — 홈
- `index.html#eel` — 제품 상세 (순살 민물장어)
- `index.html#story` — 아이해담 이야기
- `index.html#brand` — 브랜드 가이드 (내부용)

## 운영 설정
`index.html` 하단 `<script>`의 `SITE` 객체에서 수정합니다.
- `smartstoreUrl`: 스마트스토어 상품 주소를 넣으면 모든 구매 버튼이 연결됩니다.
- `categories`: 제품 카테고리. 판매를 시작하면 `status`를 `"live"`로 바꿉니다.
- `info`, `faq`: 제품 정보 표와 자주 묻는 질문.

## 확인 후 입력할 정보
원산지, 중량, 가격, 원재료, 영양정보, 알레르기, 소비기한, 배송·교환·반품, 사업자 정보는 실제 확인 전까지 비워 두었습니다. 이미지는 모두 임시 그래픽이며 실제 사진으로 교체할 예정입니다.
