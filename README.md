# 아이해담 AIHAEDAM

엄마의 기준으로 고른, 아이를 위한 좋은 수산물.

## 구조
| 경로 | 내용 | 대상 |
|---|---|---|
| `/` (`index.html`) | 고객용 온라인 쇼핑몰: 홈, `#shop` 전체상품, `#eel` 상품 상세, `#story` 이야기, `#standard` 상품 고르는 기준, `#help` 고객센터 | 고객 |
| `/review/` | 사업성 검토 v3 (개시 조건, 시장·경쟁, 공급망, 안전·배상, 배송, 손익, 추진 전략, 체크리스트) | 내부 |
| `/review/v2.html` | 사업성 검토 v2 보존본 | 내부 |
| `/guide/` | 브랜드 가이드 (철학, 로고, 컬러, 폰트, 패키지, 카피, 확장) | 내부 |

고객용 쇼핑몰에는 내부 페이지로 가는 링크가 없습니다. 검토 페이지에서 `?from=review`로 들어온 경우에만 쇼핑몰 상단에 "사업성 검토로 돌아가기" 띠가 보입니다.

## 쇼핑몰 운영 설정
`index.html` 하단 `<script>`의 `SHOP` 객체에서 수정합니다.
- `smartstoreUrl`: 스마트스토어 상품 주소를 넣으면 구매·장바구니 버튼이 연결됩니다. 비어 있으면 "연결 예정" 안내만 뜹니다.
- `images`: 사진 경로(예: `assets/img/hero.jpg`)를 넣으면 '사진 준비 중' 영역이 실제 사진으로 바뀝니다.
- `products`, `categories`, `eelInfo`, `faq`: 상품, 카테고리, 상세정보, 자주 묻는 질문.

## 주의
- 내부 페이지(`/review/`, `/guide/`)에는 공급가·손익·생산처 정보가 있습니다. 저장소가 공개 상태이면 주소를 아는 누구나 볼 수 있습니다.
- 모든 페이지에 검색엔진 수집 금지(noindex) 표시가 있습니다. 쇼핑몰을 정식 오픈할 때 `index.html`의 `<meta name="robots" content="noindex, nofollow">` 한 줄을 지우세요.
- 금액·판매량은 검증 전 추정치이며 법률·세무·보험 자문이 아닙니다.
